# ゴージャス地図（仮称）

場所の共有を、**地球儀から始まる大げさなズーム演出**で面白くする Web アプリ。

受信者は共有URLを開くだけで、「そぉ～れ」の声とともに地球がグルグル回り、目的地でピタッと止まる → 指がビシッと指して「ここぉ！」→ タメ → 「ズン、ズン、ズーーン！！」の3段ズーム＋集中線 → ピン着地と、光線・衝撃波・紙吹雪とともに場所名がドーンと着地 → 実用的な周辺地図、の順に見られます。
ログイン・DB なし。地点はURLの中だけに入っています。

- 閲覧：`https://APP_ORIGIN/?v=1&lat=35.658581&lng=139.745433&name=%E6%9D%B1%E4%BA%AC%E3%82%BF%E3%83%AF%E3%83%BC&z=17`
- 作成：パラメータなしの `https://APP_ORIGIN/` を開く

## 起動・ビルド

Node.js 20 以上（22 で確認）。

```sh
npm install
npm run dev        # http://localhost:5173  （短縮URL展開API /api/resolve-map-url も同じサーバーで動く）
npm test           # ユニットテスト（URL往復・入力検証・Googleマップ URL パーサー・短縮URL展開の境界）
npm run build      # 型チェック + dist/ に出力
npm run preview    # ビルド結果の確認（API 付き）
```

### Cloudflare Pages へのデプロイ

静的フロント（`dist/`）＋ Pages Functions（`functions/api/resolve-map-url.ts`）の構成です。

```sh
npm run build
npx wrangler pages deploy        # wrangler.toml の pages_build_output_dir = "dist" を使う
# ローカルで本番相当を試す: npx wrangler pages dev
```

Git 連携でデプロイする場合は「ビルドコマンド `npm run build`／出力ディレクトリ `dist`」を設定します。
`functions/` は Pages が自動で関数としてデプロイします。

**推奨**：Cloudflare ダッシュボードで `/api/resolve-map-url` に Rate Limiting ルール（例：1IP あたり 20 回/分）を設定してください。
関数内にもレート制限はありますが、アイソレート単位のベストエフォートです。

ホストを変えても URL データ仕様は変わりません（`APP_ORIGIN` が変わるだけ）。
短縮URL展開を使わないなら、`dist/` だけを任意の静的ホスティングに置いても動きます（短縮URLの取り込みだけが「展開できませんでした」になり、手入力に誘導されます）。

## 環境変数

`.env.example` を `.env.local` にコピーして設定します。どれも **公開されるフロント用の値**です（秘密キーは置かないこと）。

| 変数 | 既定 | 内容 |
| --- | --- | --- |
| `VITE_MAP_STYLE_URL` | `https://tiles.openfreemap.org/styles/liberty` | MapLibre 用スタイル JSON の URL（タイル配信元） |
| `VITE_GEOCODER_URL` | `https://photon.komoot.io/api/` | 「地名・住所で探す」の Photon 互換 API。空文字で機能を無効化 |

## 地図エンジン・配信元・帰属表示

- **地図エンジン**：MapLibre GL JS **6.11.2（固定）**。`projection: globe` で地球儀として描画し、同じ地図インスタンスのまま市街地まで寄ります（地球儀と詳細地図の切り替えなし）。
- **タイル配信元（既定）**：[OpenFreeMap](https://openfreemap.org/)（OpenStreetMap データ、OpenMapTiles スキーマ、APIキー不要）。
  - ラベルは `name:ja` を優先し、無ければ現地名を表示するようスタイルを読み込み時に書き換えています。
  - OpenFreeMap は寄付で運営される無料サービスで、SLA はありません。**本格公開・大量アクセスが見込まれる場合は**、MapTiler / Stadia Maps などの商用配信元か自前ホスティングに切り替えてください（`VITE_MAP_STYLE_URL` を変えるだけ）。キー付きの配信元を使う場合は、提供元の機能で**利用ドメインを制限**してください。
  - 料金・利用条件は必ず配信元の最新の規約を確認してください。
- **帰属表示**：地図の左上（イベント名タイトルがあるときはその下）に MapLibre 標準の帰属表示（© OpenFreeMap © OpenMapTiles © OpenStreetMap contributors）を常時出しています。演出中も隠しません。
- **フォント**：吹き出し・効果音文字だけ Google Fonts の「Dela Gothic One」を `text=` で必要な文字に限定して読み込みます。取得できなくても端末のフォントで表示されます。
- **地名検索（任意）**：公開 Photon（komoot）を、ユーザーが「探す」を押したときだけ呼びます。候補を選ぶとピンが移動するだけで、必ず地図での確認を促します。大量利用時は自前の Photon を立てるか、`VITE_GEOCODER_URL=` で無効化してください。

## URL データ仕様

| パラメータ | 必須 | 内容 |
| --- | --- | --- |
| `v` | 任意 | URL 形式のバージョン。省略時 `1`。それ以外はエラー |
| `lat` | 必須 | 緯度。10進表記のみ（`1e3` や空文字は不可）。-85.051129〜85.051129（Web メルカトルの表示範囲。極地はエラーにして丸めない） |
| `lng` | 必須 | 経度。-180〜180 |
| `name` | 必須 | 場所名。前後空白除去後 1〜100 文字（絵文字1つ＝1文字） |
| `event` | 任意 | イベント名（例：「佐藤さん送別会」）。最大 100 文字。空なら出力しない。閲覧画面では最初から最後まで上部タイトルとして表示 |
| `note` | 任意 | 補足。最大 200 文字。空なら出力しない |
| `z` | 任意 | 到着時の倍率。既定 17、15〜19 |

- 生成時は既知パラメータだけを `URLSearchParams` で組み立て直し、座標は小数6桁。空白は `%20` にします。
- 主要パラメータの重複・不正な数値・未対応 `v`・必須欠落はエラー画面（理由と作成画面への導線）。別の地点に置き換えません。
- `utm_*` など未知のパラメータは無視します。
- 文字列は常にテキストとして描画します（HTML として解釈しない）。

## Googleマップ共有URLの取り込み（ベストエフォート）

解析は `src/lib/googleMaps.ts` に集約しています（非公開形式への依存はここだけ）。

| 入力 | 結果 |
| --- | --- |
| `…/maps/search/?api=1&query=緯度,経度`（公式 Maps URLs） | 施設位置として採用 |
| `maps.google.com/?q=緯度,経度`、`q=loc:…`、`q=緯度,経度(ラベル)` | 施設位置として採用（ラベルは場所名候補） |
| `…/maps/place/名前/@…/data=…!8m2!3d緯度!4d経度…` | `!3d!4d` を施設位置、`/place/` の名前を場所名候補。`@` の表示中心とは区別 |
| `…/maps/place/35.65,139.74/` や度分秒表記 | 施設位置として採用 |
| `…/maps/@緯度,経度,15z`、`center=`、`ll=` だけ | **表示中心**（partial）。ピン確認を強く促す |
| 名前だけ（`ftid` のみの施設URLなど） | 名前だけ反映し、座標はユーザーが指定 |
| Place ID だけ（`query_place_id`、`cid` など） | 未解決。手入力へ誘導 |
| 経路（`/maps/dir/`、`saddr`/`daddr`、`destination`） | 非対応と案内。一地点を勝手に選ばない |
| `maps.app.goo.gl/…`、`goo.gl/maps/…` | サーバー API で展開してから上記の解析 |
| Googleマップの共有テキスト（「店名\nURL」） | URL を取り出し、名前が取れないときだけ1行目を名前候補に |

### 短縮URL展開 API：`POST /api/resolve-map-url`

```jsonc
// 入力
{ "url": "https://maps.app.goo.gl/..." }
// 出力
{ "status": "resolved|partial|unsupported", "lat": 35.6 | null, "lng": 139.7 | null,
  "name": "…" | null, "coordinateKind": "place|viewport|unknown", "message": "…", "source": "short|long" }
```

安全策（`server/resolveMapUrl.ts`）：

- 取得するのは `maps.app.goo.gl` と `goo.gl/maps/…` だけ（HTTPS・既定ポート・認証情報なし）。任意URLのプロキシにはならない。
- リダイレクトは自動追従せず、1ホップごとに転送先を検証。最大 5 回。全体 5 秒でタイムアウト。
- 転送先が長い Googleマップ URL になった時点で**取得をやめて URL 文字列だけを解析**（HTML は読まない＝スクレイピングしない。本文は読まずに破棄するので取得サイズは 0）。
- `consent.google.com` に飛ばされた場合は `continue=` の URL を取り出して解析（取得はしない）。
- リクエスト本文 4KB まで、別オリジンからの呼び出しは 403、レート制限 20 回/分/IP（ベストエフォート）。
- 失敗しても入力画面の内容は消えず、手入力とピン調整で共有URLを完成できます。

将来、Places API 等で精度を上げる場合は、この API の中に「名前だけ取れたときの補助」として追加できます（秘密キーはサーバー側の環境変数に）。

## 演出の調整

タイミング・倍率・揺れ・集中線の強さは `src/show/config.ts` にまとめてあります。

```
0.10–0.85s 「そぉ～れ」の吹き出し（ゆらゆら揺れて、回り始めてすぐ消える）
0.00–1.40s 地球がグルグル（2周半、地軸を傾けて高速回転 → 急ブレーキ → 少し行き過ぎてピタッ）＋左右の回転線、背景の後光
1.40–1.58s 地球が止まってから指が入り、地点にビシッ（衝撃線） / 1.60s「ここぉ！」（後光が金色に）
1.82–2.30s タメ / 2.30–4.35s 3段ズーム（z≈4.6 → z≈10.2 → 最終）＋集中線＋着弾ごとの揺れ・効果音文字
4.35–4.95s ピン落下・着地の波紋と火花・場所名が叩きつけられる（文字は出さず、カード後ろの光線・衝撃波・紙吹雪キャノンで「バ・バーン！」） / 〜5.75s 余韻 / 5.75s〜 共有などの操作UI
```

- 回転量・ブレーキ・傾き・セリフの文言も `config.ts` で変えられます（`globeIn`、`lines`）。
- エフェクト（`src/show/fx.ts`）：背景の後光、回転線、ズーム各段とピン着地の衝撃波リング、着地の火花、場所名カードの後ろから噴き出す光線と衝撃波、左右下からの紙吹雪キャノン、カードまわりのキラキラ。白い光は最後の段と着地の2回だけ・弱めにして、連続点滅にならないようにしています。

### BGM・効果音

- `src/show/sound.ts` が Web Audio API でその場で合成します（音声ファイル・外部通信・ライセンス不要）。
  ビート（150BPM）、回転中のスネアロールと風切り音、止まる「キュッ」、指の「ビシッ」、「ここぉ！」のジャン、タメの低音トレモロ、各ズームの上昇音と低音ドーン、着地の「バ・バーン！」ファンファーレとシンバル、余韻のキラキラ。
- ブラウザの自動再生制限のため、**共有リンクは無音で始まり、「🔇 音を出す」をタップすると途中からでも鳴ります**。一度オンにした端末では次回から自動で鳴らそうとします（ブラウザが許可した場合のみ）。好みは端末の localStorage にだけ保存します。
- 入力画面のプレビューはボタン操作の直後なので最初から鳴ります。
- iPhone はマナーモード（消音スイッチ）中だと Web Audio が鳴らないことがあります。

- 演出は「経過時間 t の純関数」として毎フレーム描画しています（`src/show/show.ts`）。スキップ＝t を終端へ、もう一度＝t=0 から。タイマーやコールバックが残りません。
- 状態は `loading → globe → pointing → pause → zooming → arrival → settled`（画面の `data-phase` 属性にも出ます）。演出中は地図操作を止め、`settled` で解放します。
- 準備（スタイル・初期タイル・演出で通るズーム段のタイル先読み・フォント）が終わってから 0 秒を開始します。
- `prefers-reduced-motion: reduce` では地球・ズーム・揺れ・集中線を省略し、0.7 秒で結果へ。
- WebGL 非対応・地図の通信失敗・WebGL コンテキスト消失時は、場所名・補足・座標・Googleマップリンク・共有ボタンを出します（6 秒以上かかると「地図なしで見る」も出ます）。
- スマホ横向き（高さ 540px 以下）では場所名カードを右側に置き、ピンと道路を隠さないようにしています。

## 残る制約

- Googleマップ URL の解析は非公開形式に一部依存しており、Google 側の変更で取れなくなる可能性があります（手入力・ピン調整で必ず完成できます）。
- 最近の Googleマップアプリの短縮URLは、展開先に施設座標を含まないことがあります（`ftid` のみ）。その場合は名前だけを反映します。
- 極地（緯度 ±85.05° 超）は表示できないため、エラーにします。
- 複数地点・経路・現在地・動画書き出しは対象外です。
- アプリ名は仮称です。特定の芸人・人物に関する名前・肖像・音声などは使っていません。
